NameGuard — 한글 파일명 자동 정리

macOS 13 이상 / Apple Silicon + Intel

1. ZIP을 풀어 설치.command와 NameGuard Desktop.app을 같은 폴더에 둡니다.
2. 설치.command를 실행합니다.
3. 맥 상단 바의 NameGuard 아이콘을 눌러 사용합니다.

새 설치는 바탕화면부터 감시합니다. 폴더 추가…에서 여러 폴더를 선택할 수 있습니다.
폴더 이름 → 감시에서 제거로 감시를 해제합니다. 하위 폴더도 포함됩니다.
일시중지 / 감시 재개 / 다시 시작 / 로그 폴더 열기 / 종료를 제공합니다.
설정은 다음 로그인에도 유지되며 기존 설치를 업데이트하면 Dropbox 등 기존 설정을 보존합니다.

종료는 이번 세션의 앱을 닫습니다. 자동실행해제.command는 다음 로그인 자동 실행도 해제합니다.

macOS가 실행을 차단하면 시스템 설정 → 개인정보 보호 및 보안에서 메시지를 확인하세요.
이 앱은 개발자 ID 서명과 Apple 공증이 없는 개인 공유용입니다.
바탕화면 접근 권한이 거부되면 해당 화면에서 NameGuard의 권한을 확인한 뒤 다시 시작해 주세요.

파일 내용은 변경하지 않습니다. 실제 NFD 한글 이름만 NFC로 정리합니다.
숨김 파일·앱 패키지·심볼릭 링크를 제외하고 기존 파일 덮어쓰기를 금지합니다.
열린 파일과 주요 편집 프로그램이 사용 중이면 변경을 보류합니다.
편집 프로젝트 내부의 파일 경로는 수정하지 않으므로 경로를 고정해야 하는 폴더는 감시에서 빼 주세요.
Mac에서 성공한 이름 변경이 Dropbox를 통해 Windows에도 반영되는지는 별도 확인이 필요합니다.

설정/로그: ~/Library/Application Support/NameGuardDesktop/
기존 설치 업데이트: 기존 ~/Library/Application Support/NameGuard/ 사용
업데이트 확인… → 다운로드 → 재시작·설치로 새 버전을 받을 수 있습니다.
다운로드를 검증하고 새 앱이 실행되지 않으면 이전 앱으로 복구합니다.
기존 1.1 사용자는 이번 설치.command를 한 번 실행한 뒤부터 메뉴 업데이트를 사용하세요.
로그인 시 자동 실행 체크로 다음 로그인의 자동 실행을 켜거나 끌 수 있습니다.
macOS 시스템 설정에서 백그라운드 실행이 꺼진 경우 로그인 항목 설정 열기를 눌러 확인하세요.
