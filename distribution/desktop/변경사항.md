NameGuard 1.3.0

- 한글 파일·폴더 자동 정리와 기존의 간단한 메뉴 구성을 유지합니다.
- 감시 폴더·제외 설정·대기 시간·일시중지·자동 실행 선택을 그대로 이어받습니다.
- 열린 파일, 편집 프로그램 사용 중인 항목과 반복 동기화가 감지된 항목은 계속 보류합니다.
- **로그인 시 자동 실행**, **업데이트 확인… → 다운로드 → 재시작·설치**를 계속 사용할 수 있습니다.
- 업데이트 파일의 크기·SHA-256·앱 정보를 검사하고, 새 앱 실행 실패 시 기존 앱으로 복구합니다.

1.2.0·1.2.1 사용자는 앱의 **업데이트 확인…**으로 설치할 수 있습니다. 1.1 사용자는 ZIP을 풀고 **설치.command**를 한 번 실행해 주세요.

macOS 13 이상, Apple Silicon·Intel 지원. 시스템 설정에서 NameGuard의 백그라운드 실행이 꺼져 있으면 **로그인 항목 설정 열기**에서 허용해 주세요.
