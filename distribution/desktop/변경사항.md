NameGuard 1.2.0

- 메뉴의 **업데이트 확인… → 다운로드 → 재시작·설치**로 새 버전을 받을 수 있습니다.
- 다운로드 파일의 크기·SHA-256·앱 정보를 검사하고, 새 앱 실행 실패 시 기존 앱으로 복구합니다.
- **로그인 시 자동 실행**을 메뉴에서 확인하고 켜거나 끌 수 있습니다.
- 앱을 직접 실행할 때 기존 설치와 다른 설정 폴더를 읽던 문제를 수정했습니다.
- 재설치 시 비활성화된 자동 실행 등록도 다시 켭니다. 감시 폴더·제외 설정·일시중지 상태는 보존합니다.

기존 1.1 버전에는 업데이트 메뉴가 없으므로 이번에는 ZIP을 풀고 **설치.command**를 한 번 실행해 주세요. 이후 업데이트는 앱 메뉴에서 가능합니다.

macOS 13 이상, Apple Silicon·Intel 지원. 시스템 설정에서 NameGuard의 백그라운드 실행이 꺼져 있으면 **로그인 항목 설정 열기**에서 허용해 주세요.
